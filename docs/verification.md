# Verification record

The Python model is an integer/bit-accurate reference for this RTL, not a call to OpenCV Canny. The fixed-point CORDIC was checked over all 1,042,441 first-quadrant Sobel pairs in software and more than 16,000 RTL vectors; the corrected 16-stage numeric path and later timing-only version had zero RTL/model mismatches in the recorded tests (`reports/PHASE4_CORDIC_CORRECTION.md`, `reports/PHASE4B_TIMING_CLOSURE.md`). Stage-by-stage image comparison covered Gaussian, Sobel, magnitude/direction, threshold class, NMS and local promotion (`reports/PHASE5_BIT_ACCURATE_GOLDEN_MODEL.md`). Frame-border tests established independence from preceding-frame line-buffer history (`reports/PHASE5B_FRAME_BORDER_CORRECTION.md`).

Runtime LOW/HIGH values were tested at boundaries and across frame-atomic updates, including fixed 50/100 equivalence (`reports/PHASE6_RUNTIME_THRESHOLDS.md`). The Phase 7 software study compares the hardware's one-pass local promotion with independent recursive 8-connected hysteresis; these are deliberately different algorithms (`reports/PHASE7_HYSTERESIS_DECISION.md`). Phase 8 compared the adaptive RTL against Python over 3,072,000 output pixels/3,000 blocks with zero mismatches, and Phase 9 verified all six block/bin configurations (`reports/PHASE8_BLOCK_ADAPTIVE_SINGLE_ENGINE.md`, `reports/PHASE9_DESIGN_SPACE_EXPLORATION.md`). Phase 10 found zero mismatches across two full frames and 600 block thresholds for each of E=1/2/4 (`reports/PHASE10_MULTI_ENGINE_SCALING.md`).

The Phase 11 board wrapper passed RTL image/UART protocol simulation. Phase 11V checked 2,100 monkey pixels in the synthesized netlist, all 307,200 monkey pixels in the routed **functional** netlist, and the 38,426-byte serialized simulated UART packet (CRC valid, zero edge mismatches). Static routed timing met 100 MHz and DRC had zero findings. The SDF-annotated timing netlist reported BRAM hold warnings before output pixels and did **not** pass; no model check was suppressed to call it green. See `reports/PHASE11V_NO_BOARD_VALIDATION.md` and `reports/phase11v/SDF_HOLD_DISCREPANCY.md`.

No physical FPGA was programmed. The 339,885 processing cycles are from a simulated wrapper counter; 3.39885 ms is computed at 100 MHz. The 0.204 W Vivado vectorless power report has low confidence. Neither figure is a board measurement.
