# Phase 8 post-NMS coordinate contract

This specification was written before histogram RTL. Phase 8 fixes `FRAME_WIDTH=640`, `FRAME_HEIGHT=480`, `BLOCK_W=BLOCK_H=32`: 20 columns × 15 rows = **300 blocks**, with no partial blocks. The workspace was clean at `9c49b95`; protected Phase 6 and earlier RTL remain untouched.

The output of the existing NMS stage is a full 640×480 valid raster. Advance `(x,y)` **only when post-NMS `href && clken` are both high**: `x` counts 0…639, rolls to 0, and increments `y` through 479; frame VSYNC establishes a fresh frame. Each valid post-NMS sample is owned exactly once by `block_x=x>>5`, `block_y=y>>5`. Histogram write and later stripe replay must use this **post-NMS output-raster coordinate**, not the input arrival clock or a guessed geometric center.

`rtl/phase5b/canny_nonLocalMaxValue_phase5b.v:22-39` uses `matrix_generate_3x3_phase5b` and registers its result and matrix controls together. The matrix has two 640-sample line delays, two registered control stages and a horizontally causal 3×3 shift window (`rtl/phase5b/matrix_generate_3x3_phase5b.v:24-46,61-101,105-139`). `scripts/phase8/probe_coordinates.py` tags every input matrix pixel by coordinate and probes the *old center tap* at each valid output slot. For normal interior samples, output slot `(x,y)` carries a center from `(x-1,y-1)`: e.g. output `(10,3)` centers `(9,2)` and output `(100,5)` centers `(99,4)`. Output row 0 and column 0 have unavailable/zero center history. Last geometric row/column are not emitted as centered samples by this causal transport. The exact border values follow the frame-isolated Phase 5B window policy, not post-hoc padding.

The later Phase 8 magnitude NMS must preserve the **same output controls and causal window**. Thus the histogram and buffered replay refer to identical post-NMS slots even though their geometric centers lag by one row/column. A fixed-mode comparison against Phase 6 is valid by ordered output-raster sample, with no arbitrary image shift. The existing Phase 6 line blanking is 24 clocks/row; the first valid NMS sample is delayed in clocks by upstream Gaussian/Sobel/CORDIC/NMS registers, but the valid sample count remains 307,200 per frame. Cycle latency must be remeasured for the new buffered path and is not used to infer block position.

This Phase 8 architecture is **not** independently processed overlapping tiles: Gaussian, Sobel, CORDIC and NMS run once globally in raster order; only threshold statistics and selection are block-local. Consequently NMS still compares across block boundaries, and the subsequent one-pass local promotion must consume a normal full-frame raster without resetting at block boundaries.
